## ✦ À propos

**Roxwood Network** est une entreprise spécialisée dans la conception et le développement de solutions web au sein de **Roxwood**.

Notre objectif est simple : proposer des sites modernes, rapides et professionnels aux entreprises et acteurs de la ville.

Chaque projet est conçu pour offrir une identité visuelle forte, une navigation fluide et une expérience adaptée aussi bien aux ordinateurs qu'aux appareils mobiles.

---

## 🚀 Le projet

Ce dépôt contient le code source du **site officiel de Roxwood Network**.

Le projet a été conçu avec une approche volontairement légère afin de permettre un déploiement rapide, une maintenance simplifiée et d'excellentes performances.

### ✨ Principales caractéristiques

* 🎨 Interface moderne et responsive
* ⚡ Chargement rapide
* 📱 Compatible mobile, tablette et ordinateur
* ♿ Navigation accessible au clavier
* 🔍 Structure HTML sémantique
* 🎞️ Animations fluides
* 🌓 Design sombre orienté technologie
* 📦 Aucun framework lourd
* 🔧 Aucun système de compilation nécessaire
* 🌐 Déploiement possible sur n'importe quel serveur web statique

### Pourquoi du HTML/CSS/JS natif ?

Roxwood Network privilégie une architecture simple et efficace.

Le site ne nécessite :

* ❌ aucun framework
* ❌ aucun bundler
* ❌ aucune compilation
* ❌ aucun serveur Node.js
* ❌ aucune dépendance externe obligatoire

Le résultat est un site léger, facilement transportable et particulièrement simple à maintenir.

---

## ⚡ Performance

L'architecture du site a été pensée autour de plusieurs principes :

**Minimalisme**

Le nombre de dépendances externes est réduit au strict nécessaire.

**Performance**

Le navigateur peut charger directement le document sans passer par une chaîne de compilation.

**Compatibilité**

Le site repose sur des technologies web standards compatibles avec les navigateurs modernes.

**Responsive Design**

L'interface s'adapte automatiquement aux différentes résolutions d'écran.

---

## 🌐 Ressources externes

Le site utilise uniquement les ressources externes nécessaires au chargement des typographies :

```text
fonts.googleapis.com
fonts.gstatic.com
```

En cas d'indisponibilité de ces services, des polices système prennent automatiquement le relais.

Aucun framework externe ou service tiers n'est nécessaire au fonctionnement principal du site.

---

## 🔐 Respect de la vie privée

Le site a été conçu avec une approche minimaliste concernant les données utilisateur.

* Aucun compte utilisateur nécessaire
* Aucun système de tracking intégré
* Aucun cookie publicitaire
* Aucune collecte inutile de données personnelles
* Navigation accessible sans inscription
